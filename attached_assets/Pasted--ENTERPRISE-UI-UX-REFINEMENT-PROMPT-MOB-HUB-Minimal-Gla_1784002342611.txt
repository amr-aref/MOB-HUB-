# GLASSMORPHISM SYSTEM

Apply glass effects carefully.

Glass should feel subtle.

Never overuse blur.

Use glass only on:

* Navigation
* Search Bar
* Filter Panels
* Floating Cards
* Modals
* Side Panels
* Bottom Sheets
* Dropdowns
* Floating Action Buttons

Glass Specification:

Background:

rgba(255,255,255,0.06)

Border:

1px solid rgba(255,255,255,0.08)

Backdrop Blur:

16px–24px

Shadow:

Very soft

No heavy shadows.

Rounded corners:

18–24px

Avoid neon.

Avoid glow.

Avoid gradients everywhere.

Glass should disappear into the interface naturally.
