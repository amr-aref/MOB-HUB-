FEATURES TO IMPLEMENT
==================================================================

1. Conversation System

Implement conversations between buyers and sellers.

Each conversation belongs to:

• Buyer
• Seller
• Store
• Optional Product

Conversation list must display:

• last message
• unread count
• timestamp
• participant
• store

==================================================================

2. Message System

Support:

• Text Messages
• Image Messages (architecture ready)
• System Messages

Each message must contain:

• id
• conversationId
• sender
• receiver
• createdAt
• status
• type
• content

==================================================================

3. Chat Screen

Create a professional chat experience.

Include:

• message bubbles
• timestamps
• read/unread states
• typing area
• auto scroll
• empty state
• loading state
• error state

==================================================================

4. Store Integration

From Store Detail

"Message Seller"

must immediately open or create a conversation.

Never create duplicate conversations.

==================================================================

5. Product Integration

From Product Detail

"Ask About Product"

opens conversation linked to the selected product.

==================================================================

6. Dashboard Integration

Seller Dashboard

New Messages section must display:

• latest conversations
• unread messages
• quick open chat

Design proper normalized schema.

Tables should support future scalability.

Include relations for:

• Conversations
• Participants

Professional messaging experience.
